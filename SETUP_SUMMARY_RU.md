## Как сделать чтобы бот работал с других устройств (полная функциональность):

### Способ 1: Deploy на хостинг с HTTPS (рекомендуемый)
1. Зарегистрируйтесь на [PythonAnywhere](https://www.pythonanywhere.com/), [Render](https://render.com/) или [Vercel](https://vercel.com/)
2. Загрузите туда файл `index.html`
3. Получите HTTPS-ссылку (например, `https://block-blast.pythonanywhere.com`)
4. В боте установите переменную окружения:
   ```bash
   export WEBAPP_URL=https://ваш-домен.com
   ```
5. Перезапустите бота: `python3 bot.py`
6. Теперь в /start появится кнопка "🎮 Открыть игру в Telegram"
7. Пользователи со всех устройств смогут играть как в Mini App!

### Способ 2: Использовать ngrok (для теста)
1. Установите ngrok: `brew install ngrok` (mac) или скачайте с ngrok.com
2. Запустите туннель: `ngrok http 8443`
3. Скопируйте адрес вида `https://abcd1234.ngrok.io`
4. Установите `WEBAPP_URL=https://abcd1234.ngrok.io`
5. Перезапустите бота
6. Кнопка "🎮 Открыть игру в Telegram" заработает!

## Управление в игре:
- **Перетаскивайте** фигуры из нижней панели на игровое поле 8×8
- **Заполняйте** целые строки или столбцы — они исчезают
- **Набирайте очки** за каждую очищенную линию
- **Игра заканчивается**, когда не поместится ни одна фигура
- **Кнопка "Новая игра"** внизу поля или команде /play
